# Contributing to BiblioCase

BiblioCase is primarily a personal demo project developed by Dennis.

The project is under active development, and its architecture, functionality and technologies may change as development progresses.

## Development

* Follow the project's `.editorconfig` and existing code conventions.
* Keep commits focused and describe what has changed.
* Repository-level configuration should only be added when it serves a clear purpose.
* Development tooling and local configuration should not be committed unless it is intended to be shared.

## Project status

BiblioCase is a work in progress. Documentation and conventions may therefore change as the project evolves.
