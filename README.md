A book application currently under development.

The application is built with:

- .NET 10
- ASP.NET Core Web API
- Blazor
- Entity Framework Core
- PostgreSQL

The application is being developed as a demo project and is intended
to demonstrate modern .NET development, web APIs, database access and
Blazor-based UI development.

Running the application

BiblioCase consists of two applications that are started separately:
- BiblioCase.Api – ASP.NET Core Web API
- BiblioCase.Web – Blazor web application

> **Work in progress:** The application is still under development and
> functionality and architecture may change as the project evolves.
